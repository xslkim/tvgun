# 故障排查

- **裁切错位或沾到邻件。** 检查原图裁框和遮罩。按 Alpha >30 裁后边界定位锚点。背景为渐变时用遮罩或重新取得透明件。
- **配件消失或肢体叠错。** 对照设定图确认近远侧及附件顺序，检查躯干是否重复画了关节。动作中会露出的部位需要完整贴图。 [黄铜信使复检](../../../assets/courier/qa/visual_recheck.md)
- **旋转错误或开缝。** `imageAxis` 是原贴图骨轴的世界角。核对裁后锚点、关节交叠和骨轴，检查绑定与极限姿势。
- **脚滑、关节跳变或贴图穿地。** 按 QA 时间点检查接触区间、地速、IK 可达性和角度曲线。再用实际贴图核对剑尖、翼尖和足底。
- **本地预览加载失败。** 用 `node demos/viewer/serve.mjs` 启动，检查 `demos/characters.json` 和角色的导出索引。首次检出时确认 Git LFS 已取回素材。
