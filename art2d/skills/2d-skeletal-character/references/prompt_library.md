# 提示词模板

用角色实际设定替换大括号内的字段。工作板中的组装图用于核对身份，独立件用于绑定和补全遮挡。

> 原创 {角色和识别特征}，用于 {游戏视角与画风}。保持 {体型比例、配色、光向}。同一工作板提供一张标准姿势的完整设定和 {指定部件清单}。各部件独立、透明背景、有充足间距，关节端保留可旋转的重叠区域，隐藏面完整。无背景、地面阴影、文字和水印。
