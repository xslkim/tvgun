# 黄铜信使 · 设定图与动画复检

初版的自动 QA 检查了关节和接地，但漏判了美术一致性。设定图有红围巾、位于近侧的空手臂和较完整的靴形。初版沿用了独立工作板里的其他比例，胸甲和手臂重复绘制肩球，并把持剑臂画在近侧。

- 以同一张原图的组合设定为主要切件来源，重做头、围巾、盔甲、四肢、靴与剑的裁框、遮罩和锚点。设定图遮挡的持剑侧上臂使用同板独立臂件补全。 [原图](../concept/raw.png) · [拆件配置](../concept/layout.json)
- 绘制顺序为持剑臂与剑、远腿、近腿、躯干、围巾、头、近侧空手臂。握剑的手压在剑柄上，领圈与飘尾独立。 [骨架配置](../concept/rig_layout.json) · [等比例对照](../preview/master_vs_bind.png)
- 重新烘焙全部 14 段。待机、走跑、举剑和挥剑检查肩部接合与持剑侧遮挡；跳跃、落地和倒地检查脚、剑尖和围巾的地面关系。自动检查为 0 错误。30 fps 默认剑款渲染中，14 段均未测得实色像素穿地。 [关键帧 1](../preview/review_1.png) · [关键帧 2](../preview/review_2.png) · [像素测量](../preview/raster_metrics.json) · [QA](REPORT.md)
