# 骨骼绑定规范

骨骼按父先子后排列。世界坐标用像素，+x 向右，+y 向上，角度用逆时针度数。根骨从地线原点开始，髋为重心控制。为左右侧分别确定铰链方向和绘制顺序，朝左由角色容器整体镜像。

## 原型模板

| 原型 | 绑定结构 |
| --- | --- |
| 人形 | 髋→脊柱→胸→颈→头；胸接肩、肘、手、装备；髋接大腿、小腿与脚。 |
| 四足 | 躯干接四组腿、颈头和尾。需要趾行结构时为跗跖关节单独设骨。 |
| 飞行 | 躯干接左右翼根与翼尖，膜片用相应骨骼权重。 |
| 多足 | 躯干接多组腿，分开指定每组铰链和接触点。 |
| 软体 | 底缘与顶部使用不同控制骨，装饰单独绑定。 |

[模板与样例](../../pipeline/rig/templates/README.md) 提供拓扑和初始范围。关节限位按角色确认，以 `rig/joint_limits.json` 为准。样例的机械关节范围仅适用于相应模型。

## 绑定约定

- 附件按 `rig.attachments` 顺序绘制。每件含骨名、图集矩形 `rect`、像素尺寸 `size`、裁后锚点 `pivot` 和源轴补偿 `a`。变体可覆盖矩形、锚点、尺寸和角度。样例使用固定层序；例如人形先画持剑臂、剑和握柄手，再画躯干及近侧空手臂。
- 蒙皮以 UV、三角索引和 `[骨名, 权重, 绑定局部 x, y]` 描述，顶点权重和为 1。非弹性骨保持骨长。看 `preview/joint_extremes.png`，再检查动作中的叠层与三角形变形。
- 脚用二骨 IK，显式指定末端世界位置、骨长和弯曲符号。普通关节限位比较绑定姿势下的相对角，`chain: true` 铰链以伸直为 0°。不可达目标会被 IK 限制，但声明接地的帧仍须通过 QA。
- 生产配置为 `concept/rig_layout.json` 与 `parts/anchors.json`。构建生成骨架、限位、支撑点和部件映射。 [动画与数据合同](ANIM_SPEC.md)
