# 美术生产规范

以游戏给定的设定图为准。先定视角、世界尺度、配色、光向和识别配件，再定可动部件。样例使用右向 3/4、赛璐璐描边与上左光源。样例人形 H 为 512 px；其他角色的尺度按游戏设定与 QA 所需的实际尺寸填写。 [样例设定与原图](../../pipeline/gen/README.md)

## 切件

- 先确认同尺度设定和绑定姿势。沿设定图的关节与遮挡边界切件，保留左右近远关系。被遮挡但会在动作中露出的部位用参考一致的独立部件补齐。将武器、飘带和可替换的装备单独切出。
- 保留关节交叠与隐藏面，刚性护甲用切件，膜片或软体用蒙皮。保持 Alpha 干净，地面阴影单独处理。
- `layout.json` 的裁框用原图半开像素矩形 `[left,top,right,bottom]`，可用多边形做精切。按裁后图像记录左上原点的 `[u,v]` 锚点，并在绑定配置中记录源轴。当前工具要求裁后每边至少 24 源像素。
- 角色和部位使用小写 snake case。输出 PNG 为 RGBA、straight Alpha、sRGB。当前图集不旋转，最大边 2048 px，4 px padding 并复制 1 texel 边缘。
- 保留原图、Prompt、来源和参数。构建器记录原图 SHA-256，模型或 seed 不可用时在清单写明。

## 验收

等比例对照 `preview/master_vs_bind.png`。检查剪影、服饰识别件、四肢长度、近远层序及关节拼合，再在极限姿势和实际动作中查隐藏面、肢体穿插和接地。 [黄铜信使复检](../../assets/courier/qa/visual_recheck.md) · [提示词模板](../../skills/2d-skeletal-character/references/prompt_library.md)
