# 初始工具选型（参考）

2026-11-06。当前主管线为内置图像生成工作板 → Pillow → Node JSON 骨架、解析 IK、帧采样 → QA → 图集和浏览器 Canvas。原型可用同一套规范与运行时复现。GPU 生图服务只在生产原图时需要，已保存的原图可离线重建。源格式与渲染共享世界变换函数，避免 QA 对近似格式的错判。

## 备用线路

本地 ComfyUI（GPL-3.0）+ Apache-2.0 的 FLUX.1-schnell FP8 → 高反差纯色底同板生成 → Pillow 洪泛去底 → 同一套 JSON、QA 和 Canvas。无需付费账户。要接入 Godot 可采用 MIT 的 4.6.3，经已验证的 Skeleton2D/AnimationPlayer 换轴规则导入。 [备用操作步骤](../pipeline/gen/OFFLINE.md) · [Godot 探针](research/probes/godot/RESULTS.txt)

备用生图核对了官方工作流结构和模型卡，当前未下载权重进行本机推理。Qwen-Image-Layered 验证官方分层工作流结构，可辅助补图，按解剖拆件的品质未实测。Godot 样例验证骨架/轨道，不是五类完整资源导入器。

## 实施取舍

- 为减少等待，先发起人形生图并继续调研探针，实际绑定在 POC 可播放后开始。工作板同次生成主参考和可用部件，再用坐标、锚点和少量多边形遮罩修整。这样减少跨请求风格漂移，并保留真实来源。对照了分层、分割补画、逐件重绘方案的输入输出，当前没有四策略推理成功率横评。
- 原创机械生态统一配色、剪影与像素单位，远肢共用贴图的低亮版本。部分原型合并躯干/盔甲片与触角，比例按原型设定。人形穿全甲，保持刚性切件与可变形腰部；四足后肢三段简化。
- 30 fps 输出配 120 Hz 烘焙和 QA，允许清晰捕获短动作与接触边界。允许关节范围按机械样例校准，绝对伸直角与绑定差值分开。采用时间轨迹和二骨 IK，未做视频动捕，自动 QA 之外仍检查真实图像。
- 保留 5 类×完整动作矩阵。单动作使用固定附件层序；特定冲刺与扑咬用根位移。运行时提供 150ms 过渡演示，混合期间由游戏层额外处理足接触。Boss 为可选项。
- 版本控制沿用父仓。新增 LFS 范围只覆盖本目录 AI 原图和动画 GIF，体积较小的 JSON、纹理和复检图随源保存。渲染与模型推理所需程序二进制不进入仓库。
- 内置服务只返回可观测参数，模型精确版本/seed 空值有记录。完整风险、视觉余量和验收说明见 [总结](FINAL_REPORT.md)。
