## 1. 一句话

一盏多层纸雕灯里藏着一座 1990 年代的小城。墨从黑暗里渗进来，要把它吞掉。你手里的枪是一束光。

## 2. 为什么选这个方向

### 2.1 和以往不一样

这一节是设计动机，不是市场调研结论：下面关于“常见”“少见”的判断都是印象，没有做系统检索，也没有附可核验的来源。这个项目自己和朋友玩，不需要靠新颖性立项；真想确认，再补检索。

- 皮影和水墨神话题材，近年的国产游戏里给人的印象是已经比较多；“用光源让敌人暴露弱点”这类机制也不算新。所以不选皮影。
- **纸雕灯**（多层白纸刻成剪影，叠在一起，背后打光）是近几年流行的手工艺，印象里在游戏中用得少。它的观感是层层透光、层层叠叠的深度，和平面剪纸、皮影都不一样。
- 用一门民间手艺去画一座**当代的小城**（夜市、录像厅、旧影院、绿皮火车），而不是神话。反差本身就是新鲜感。
- 光和墨的对立贯穿画面、玩法和故事：枪是光，敌人是墨，打中就是“照亮、蒸发”。

### 2.2 和光枪的硬约束天然契合

| 约束（见 GUNFORGE_PLAN 第 4 节） | 这个风格怎么满足 |
|---|---|
| 画面亮度要有上限 | 夜里点亮的灯箱，本来就是暗底、局部透光 |
| 白边内侧要暗 | 灯箱的深色木框正好就是内侧暗区，四周自然压暗 |
| 目标要好认 | 黑色的墨叠在透光的纸层上，轮廓对比最强 |
| 不能有全屏白闪 | 光的反馈只是局部光斑和墨被蒸发的烟 |

### 2.3 和 AI 生产能力天然契合

| 难点 | 这个风格的解法 |
|---|---|
| 场景要分层，敌人要能从掩体后出来 | 纸雕灯本来就是一层一层的，可以按统一白模由 GPT 逐层生成透明素材，本地组装并核对遮挡 |
| AI 画同一个角色的不同动作很难保持一致 | 纸居民是分件纸偶，关节转动由引擎做，AI 只需要画一次 |
| 墨怪的动画 | 墨是流体，蠕动、滴落、溶解都用着色器做，AI 只出静态形状；只有少数复杂动作用视频生成 |
| 过场需要角色口型 | 过场是“爷爷的磁带录音”加纸层运镜，不需要口型 |
| 站点之间的转场 | 纸层滑开、翻折、灯光切换，引擎里直接做转场演出，不需要生成视频 |

## 3. 世界观

### 3.1 背景故事

爷爷是个纸雕匠。他把年轻时住过的小城“灯城”刻进了一盏十二层的纸雕灯：夜市、录像厅、旧影院、澡堂、筒子楼、绿皮火车站。后来小城拆了，这盏灯成了它唯一的样子。

爷爷走后，你整理他的工作台，不小心碰翻了砚台。墨渗进了灯里。

那天夜里灯一亮，纸上的灯城醒了过来，墨也跟着醒了。被墨盖住的东西，就从这座城里消失了。你手里的手电是唯一能伤到墨的东西：光照到哪里，墨就在哪里化成烟。

### 3.2 世界规则

| 元素 | 规则 |
|---|---|
| 纸 | 灯城里的一切都是纸。灯亮的时候，纸居民会动、会叫卖、会骑车 |
| 光 | 灯芯的光是这座城的命。墨遮住一盏灯，那一片就暗下去；重新点亮，墨就会退 |
| 墨 | 墨本身没有形状，**吃掉什么就长成什么样子**：吃了麻雀变墨鸦，吃了自行车变墨车夫，吃了录像带就拉出长长的磁带丝。这条规则用来批量设计敌人 |
| 朱砂 | 墨里混进了爷爷落款用的朱砂印泥。每只墨怪身上都有一点朱红色的“印”，那就是它的弱点 |

### 3.3 角色

| 角色 | 说明 |
|---|---|
| 你 | 不露脸，只以光的形式存在 |
| 爷爷 | 只出现在声音里：他留在灯座里的一盘磁带，讲当年灯城的事。所有过场的旁白都是他 |
| 纸居民 | 卖糖葫芦的、录像厅老板、放映员、检票员、骑车的人。会被墨附身，需要你救 |
| 墨 | 没有意志的吞噬者。它的源头是爷爷砚台里最后一个没写完的字：“忘” |

### 3.4 主题和基调

- 主题：遗忘和记住。墨是遗忘，光是记住。
- 基调：温暖、热闹、带一点诡丽。不恐怖、不血腥，墨被打中只会化成烟和墨花。适合和朋友在客厅轮流玩（首版只有一把枪，双人以后再定）。
- 结局：打散“忘”字之后，灯城还在，磁带最后一句：“灯亮着，就还在。”

## 5. 玩法

### 5.1 基本规则

沿用 GUNFORGE_PLAN 第 5 节的框架和数值，换上这个世界的说法：

**人物定位（项目负责人 2026-11-04 明确）：** 所有人物只能是人质或 NPC，不是敌人，不设计人物攻击玩家、人物可受攻击或人物变成怪兽的玩法。人物本体没有敌方血量、攻击状态或可伤害命中区；误射纸身只作既有扣分反馈，不产生受伤或死亡。受困居民身上的墨团是独立的净化对象，清墨用于救人；人身始终是保护区。攻击和威胁只来自独立墨怪，不能借“附身”让人质投掷物件攻击玩家。

| 框架概念 | 本作叫法 |
|---|---|
| 生命 | 灯芯，5 根 |
| 弹匣 | 光，6 格 |
| 离屏换弹 | “回光”：枪口移出屏幕扣扳机 |
| 人质 | 被附身的纸居民。误伤纸身**只扣分、不扣灯芯**，覆盖框架“扣分扣血”的默认值，符合本作不恐怖的基调 |
| 续关 | `COIN` 再点一盏灯 |

### 5.2 四个招牌机制

| 机制 | 规则 | 需要的框架能力（GUNFORGE_PLAN 第 5.2 节） |
|---|---|---|
| **净墨不伤纸** | 被墨附身的纸居民身上糊着一团墨。打墨，居民获救，加分，有时掉道具；打到纸身扣分。墨团是可伤害区，纸身是保护区（命中裁决见 GUNFORGE_PLAN 第 4.4 节）。墨团要画得足够大，和纸身之间有一圈看得出的边界，不靠隐形碰撞区补救。救下的那一帧居民进入获救动画，后面连射的子弹不再算误伤 | `hostage` + 命中区 + 状态（附身 / 获救） |
| **点灯** | 路灯、招牌、灯笼被墨遮住时，那一片变暗。暗处的墨怪只露出朱砂眼，是“硬化”状态，打不动。打中灯（消耗一发），灯重新亮起，这一片的墨怪 6 秒内变软、可以击杀；6 秒后墨会重新爬上灯，可以再点。只有当这盏灯可见、可射，并且 6 秒够把这一片的墨怪打完时，硬化墨怪才允许发动攻击 | 状态（硬化 / 可伤害）+ 事件（灯亮起）+ 目标组（这一片的墨怪） |
| **墨线连锁** | 一群墨怪之间连着拉丝墨线。打掉最大的“墨源”，墨线上的墨怪沿线依次蒸发，每只间隔 0.15 秒，按蒸发的先后顺序计连击分 | 目标组（依赖和传播）+ 事件（死亡） |
| **笔顺** | 最终 Boss 是一个墨写的“忘”字。当前该打的那一笔亮起脉动的朱砂描边，笔画起点有一个毛笔落笔的小光点提示方向；按顺序打断伤害最高。打错的笔画闪一下灰、发出闷响，只有很小的伤害。不认识笔顺的玩家跟着亮的那一笔打就行 | `boss` 阶段 + 目标组（顺序） |

公平性检查：暗处的墨怪必须露出朱砂眼，玩家始终看得到威胁；硬化状态下墨怪发动攻击前同样要有预警。点灯、连锁和墨怪攻击叠加时，按 GUNFORGE_PLAN 第 5.4 节的动作成本检查，包括“只剩一发、需要先点灯、同时有多个目标”的情况。

**教学顺序：** 四个机制不同时登场，每个先单独教一次，再和别的组合。

| 顺序 | 机制 | 在哪里教 | 作用 |
|---|---|---|---|
| 1 | 净墨不伤纸 | 第一关第一个站点 | 建立“打墨救人”的感情和射击反馈 |
| 2 | 点灯 | 第一关第二个站点 | 建立节奏：先点灯，再打墨 |
| 3 | 墨线连锁 | 第一关后半段 | 熟悉之后的奖励 |
| 4 | 笔顺 | 第三关 Boss | 最后的变化，靠视觉提示学，不靠说明文字 |

这些安排能不能玩得好，要靠阶段 0B 和之后的试玩判断，文字设计证明不了有趣。

### 5.3 敌人图鉴（首款 7 种独立墨怪）

| 名称 | 吃掉了什么 | 行为 | 原语 | 预警 |
|---|---|---|---|---|
| 墨蝌蚪 | 雨后的水洼 | 成群从墨洼里游出来扑向镜头。命中按头部墨团算，头部直径 90–130，尾巴不计入；主可伤害区有效半径不小于 40 规范像素，不靠隐形放大；同一群里两只的命中区不重叠 | `approach` | 水声加群体变大 |
| 墨鸦 | 电线上的麻雀 | 从屋檐起飞俯冲 | `swoop` | 振翅声加朱砂眼亮起 |
| 滴墨 | 屋檐的雨 | 从高处滴向镜头，要在半空打掉 | `thrown` | 滴落前在檐口鼓起 |
| 墨车夫 | 二八自行车 | 骑着墨车横穿画面，途中停下甩墨 | `run_across` | 车铃声 |
| 墨招牌 | 霓虹招牌 | 从招牌后探出，吐墨球 | `popup` + `thrown` | 招牌闪烁 |
| 磁带墨 | 录像带 | 拉出长长的磁带丝缠向镜头 | `popup` + `approach` | 倒带声 |
| 墨伞 | 雨伞 | 撑伞挡光（伞面是无效区），收伞的瞬间露出墨身和朱砂印迹，墨身可打 | `popup`（带护盾） | 收伞动作 |

**人质 / NPC（不属于敌人图鉴）：** 卖糖葫芦的人、录像厅老板等纸居民只做日常、躲避、受惊、呼救、挣扎、获救和感谢动作，不做进攻或投掷攻击。附墨人质保持亮纸人形，墨团只贴胸腹，显示高度不小于 300；可射对象只登记为独立墨团，不把人物整身登记为敌人。安全 NPC 与获救居民均不产生攻击目标。

### 5.4 Boss

| 关卡 | Boss | 打法 |
|---|---|---|
| 第一关 | **墨舞龙**：夜市舞龙队的纸龙被墨附身，墨团附在各节龙身上，龙在夜市上空游走 | 从龙尾往龙头逐节清墨；龙头张嘴喷墨前会摆头预警；最后打龙头里的朱砂核 |
| 第二关 | **银幕影**：旧影院的银幕上，墨爬进了放映机的胶片，借放映机的光演出一个巨大的影子，是“屏幕里的屏幕” | 放映机光束扫过的地方会刷出敌人。三台放映机本身是正常的光源，不能打；墨缠在胶片盘上，胶片上有墨渍和朱砂印。打掉胶片上的墨（不是打灭放映机），这台放映机的光就从墨色变回暖光，反过来照亮银幕。三台都净完，影子才露出核心。这样玩家始终在“清墨、让光回来”，不会突然变成要灭灯 |
| 第三关 | **“忘”字**：镜头拉出纸灯，来到爷爷的工作台，砚台里升起一个墨写的“忘”字，共 7 笔 | 笔顺机制（提示和误射反馈见第 5.2 节）；字散掉一笔，攻击方式就变一次 |

### 5.5 关卡

| 关卡 | 站点 | Boss |
|---|---|---|
| 第一关 夜市 | 巷口、糖葫芦摊、录像厅门口、天桥、广场 | 墨舞龙 |
| 第二关 旧影院 | 售票处、海报长廊、观众席、放映室、银幕前 | 银幕影 |
| 第三关 火车站 | 候车室、站台、绿皮车厢、灯座（灯城的“底”），然后镜头拉出纸灯 | “忘”字 |

每关游玩 4–5 分钟（含站点转场和 Boss，不含关头过场），三关合计 12–15 分钟；加上第 5.6 节约 3.5–4 分钟的过场，全程约 15.5–19 分钟。这是“熟练玩家、不续关、不跳过过场”的估算，口径同 GUNFORGE_PLAN 第 5.1 节，不是所有玩法下的保证。三关的主色调依次是暖杏、品红配冰蓝、青绿配月白，让每一关一眼就能分出来。

### 5.6 过场

全部在引擎里演出：用游戏素材做纸层运镜，配爷爷的磁带旁白和字幕。只有 2–3 个特殊镜头用可灵视频生成，例如开场砚台翻倒、墨渗进灯里。

| 过场 | 时长 | 内容 |
|---|---|---|
| 开场 | 约 90 秒 | 工作台、碰翻砚台、墨渗进灯、灯亮、灯城醒来、墨也醒来 |
| 每关开头 | 20–30 秒 | 磁带里爷爷讲这个地方当年的事 |
| 结局 | 约 60 秒 | “忘”字散去，灯城还在，磁带最后一句话 |

爷爷的声音用 CosyVoice 设计：七十多岁的男声，略带北方口音，温和，讲到高兴处会笑。磁带质感（底噪、轻微变速）在后期加。

### 5.7 声音

| 类别 | 设计 |
|---|---|
| 主题旋律 | 纸雕灯底座的八音盒旋律，三关都是它的变奏 |
| 第一关 | 90 年代城市流行器乐：卡带合成器加八音盒 |
| 第二关 | 老电影配乐的弦乐，加放映机的咔嗒节拍 |
| 第三关 | 手风琴和口琴，加火车的节奏 |
| Boss | 主题旋律被墨“污染”的失真版本 |
| 开枪 | 不是枪声，是光的声音：短促的玻璃铃声加一点电流嗡鸣 |
| 命中墨 | 水滴进热油的嘶声，加墨花溅开 |
| 环境 | 夜市叫卖、自行车铃、放映机、火车汽笛 |
