# 纸灯城首站 0B 执行任务

2026-11-07。长期目标为 AI 自动开发光枪游戏的 GunForge，当前用《纸灯城》首站验证可玩性和生产闭环。T08 离线样片已通过，采用资产目录里的已核验首站包。

## 范围与顺序

1. B01 建立 Godot 工程和启动入口，打通原始资产到运行包。当前使用本机已验证的 Godot 4.6.3，Compatibility 渲染，保留版本信息。完成标准为可启动、资产哈希校验、纹理预算和实际画面截图。
2. B02 实现通用屏幕布局、规范坐标映射、独立白边与内容限亮，提供显示器和电视配置、全屏、设置保存和校准。完成标准为不同窗口、边框和配置下坐标可逆，5 点拟合及独立 4 点检查。
3. B03 实现可见 alpha 命中、前景遮挡、主区/弱点/保护区/无效区裁决。接入原生 art2d 骨架和附件顺序。完成标准为边缘、前后遮挡、近目标、救下瞬间等回归通过。
4. B04 用游戏自己的数据和规则实现点灯、区域软化、净墨救人，三轮 60–90 秒站点。加入弹匣、两种换弹、提示、生命、死亡、续关、基础音效和转场。完成标准为鼠标实际输入可通关，失败可恢复当前波次。
5. B05 提供固定时钟、输入注入、状态报告、机器人和关卡校验。完成标准为常规、低弹药、多目标、失锁暂停/恢复、死亡续关的自动回归，输出机器可读结果。
6. B06 实现 UDP 接收、发现、P1/P2 序号与失锁、P5 边框同步。核对手机现有实现，补齐所需协议并按 WORKFLOW.md 构建。完成标准为真实本机 UDP 测试通过、APK 可构建、追踪改动配套回归。
7. B07 汇总可玩入口、自动验证和实际 GPU 证据，交付用户试玩及真实光枪 0B 验收。显示器/电视录制、体验判断及真实设备测试需审核人参加。

任务按顺序实施，独立检查可同时运行。公共代码位于 `gunforge/framework/`，首款关卡与规则位于 `gunforge/games/g01/`。公共框架加载指定游戏入口，游戏代码负责点灯和墨的专属规则。
