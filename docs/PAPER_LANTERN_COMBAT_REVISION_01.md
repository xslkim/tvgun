# 《纸灯城》战斗候选 R1

依据：真实用户批注 `user-gameplay-2026-11-08`。这是独立新候选，旧 `paper.alley` 和原 Demo 保留作对照；不将新玩法的有意差异混进旧版等价性通过记录。

## 本轮要改变的行为

- F01/F02：可见的入场、曲线飞行、蓄力和扑击；远程墨鸦发射可拦截墨弹。伤害和攻击接触在同一模拟 tick 结算；击破攻击者或墨弹会取消相应伤害。被击破的怪物有消散，攻击结束的怪物有撤离，不再突然消失。
- F03：怪物始终可以射击。灯变为有冷却的可选震退支援，显示脉冲和明确的受影响反馈；朱印是弱点奖励。第一波用简短提示建立因果。
- F04：射击/命中/弱点/净化/出手/玩家受击分别配置音效和局部表现；命中有短暂顿挫与回弹，受击有墨迹和生命反馈。声音在此候选的预览中默认开启，可关闭。
- F05：六波逐步递进，路线与近远攻击组合有变化；HUD 显示波次、当前进度、总净化数、生命和弹药。保留居民是保护/救援角色，人物不会攻击玩家。

## 引擎实现边界

新增能力放在通用运行器：数据化路径、复合命中部件、实体局部时钟、短暂停顿/震退、投射物发射、表现包、分段/目标统计。游戏名、墨鸦、灯和提示文案留在内容包。

画面复用现有巷口、墨鸦与人物资源；运行时做位移、旋转、缩放、独立朱印部件和命中回弹，不更换已经确认的美术风格。墨鸦尚未新增逐帧或骨骼扑翼动画。身体/朱印共享一个实体结算，不能利用不同部件重复领奖；视觉运动与命中几何使用同一姿态。

## 这一轮的检查

必须实际运行：普通射击可击破；近身攻击造成有来源的伤害；拦截取消伤害；震退暂停动作与截止；多部件只结算一次；波次与统计正确；失败/成功/重试可达；快照、跳转和同输入回放一致。保存玩家画面、调试图和代表片段，并按 F01–F05 留下变化记录。

自然度、声音喜好、实际光枪难度和最终采用不由 Agent 自行写成通过。第一轮结果交给用户继续批注。
