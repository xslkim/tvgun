# 《纸灯城》结尾 CG · 灯亮着

2026-11-14。为完成三关后的结算制作的独立 60 秒视频。

- `paper_lantern_city_ending.mp4` 是带中文字幕的 1080p、30fps 审看版。
- `paper_lantern_city_ending_clean.mp4` 是无烧录字幕的版本，配套字幕为 `ending_zh.srt`。
- `keyframes/`、`motion/` 和 `audio/` 保存新制画面、H3 工作流与短片、逐句人声及混音分轨。

## 与成品的衔接

以仓库 `3ad41ac` 为调研基线。成品包含夜市、旧影院、火车站三关共 15 站。工作台「忘」字第七笔净化后，现有 58 秒引擎片尾由点灯、夜市、灯城全景、工作台四段组成。新视频从最后一笔的余墨落回砚台开始，保留原片尾的首句与末句，把旧影院和绿皮火车站也放进回望。

工作台参考 T15 的圆形竹骨灯、浅圆砚、挂笔与纸卷。全景参考 T15 的夜市、圆角影院、站台与河桥关系。青绿站台、暖杏夜市与紫调影院各自保留主色，人物只作为恢复日常生活的纸居民。结尾用空椅、录音机和仍然亮着的灯呼应开场。

## 剪辑与制作

- 00–06 秒，最后一笔的余墨消散。
- 06–15 秒，夜市重新开张。
- 15–24 秒，旧影院的放映机恢复运转。
- 24–34 秒，绿皮车离站，站台灯仍亮。
- 34–46 秒，拉远，看见河桥连起灯城三个街区。
- 46–53 秒，爷爷的磁带留下最后一句。
- 53–60 秒，回到空椅与纸灯，留数秒安静后淡出。

七幅关键帧由内置图像生成工具按文字新绘，工具未披露模型版本和种子。本地 MiniMax H3 生成动作片段，工作流和种子随各镜头保存。人声由本地 VoxCPM2 按文字设计，参考音色也为本轮新合成。配乐与环境音由脚本合成。成品截图和原片尾仅用于调研，未进入新视频的生成输入或成片音画。

在本地先用 `generate_ending_voice.py`、`generate_ending_motion.py` 生成音画，再用 `build_ending.py` 渲染。逐镜、旁白与秒数以 `gunforge/pipeline/cinematics/ending_plan.py` 为准。视频作为独立交付，尚未接入游戏播放器。
