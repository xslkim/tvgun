# 《纸灯城》PC 鼠标试玩验收

当前开发和验收使用 Windows PC、鼠标、键盘和 PC 扬声器或耳机。手机光枪、电视、设备校准和追踪录制安排在游戏发布验收阶段，开发可以继续。

## 启动已验证的三关候选

关闭其他正在运行的 GunForge 播放器。在 Windows PowerShell 执行以下命令。启动日志的构建号应以 `ed50339937dd` 开头。

```powershell
$godot = 'D:\gunforge_cache\tools\godot-4.6.3\Godot_v4.6.3-stable_win64_console.exe'
$stage = 'D:\gunforge_cache\t16_cast_supplies_verified'
& $godot --path "$stage/gunforge/framework" --script res://tools/level_player.gd -- "--build=$stage/level.json" "--assets=$stage" "--opening-dir=$stage/gunforge/games/g01/cinematics/opening_original" --isolated-settings
```

若本机没有这个隔离包，在仓库根目录运行 `powershell -ExecutionPolicy Bypass -File .\gunforge\start_level_player.ps1 -Package paper.lantern_city_cast -Candidate`。这一命令按本机工作区重编，请记录控制台里的实际构建号。

- 点击「开始」或按 Enter。战斗用左键射击。8 发打空后自动换弹，R 可提前换弹，Esc 暂停，Enter 恢复。
- H 切换纸环准星，F11 切换窗口和全屏，Q 退出。鼠标模式启动后直接射击。
- 想反复验证战斗时，可在启动命令里去掉整项 `"--opening-dir=..."`。第一次验收保留开场和声音。

本轮优先验证左下角生命数字、救援回血和首次点灯补弹。[三项快速复测](../supplies/report.md)

## 第一轮 · 开场、操作与第一关

| 到哪里 | 具体操作 | 通过标准 |
| --- | --- | --- |
| 开始与开场 | 鼠标移入、按下、移出按钮再松开一次，然后正常点击开始。完整看一次开场。另开一轮，用 Esc 跳过开场 | 按钮有反馈，移出后松开不开始。自然播放约 90 秒，字幕与旁白对得上，跳过后视频和音轨退出。进入巷口时是新局 |
| 巷口 | 射一个清楚的目标，再射一次场内空地。把弹匣打空一次，等自动补满再射。弹匣非满时按 R 测提前换弹。接着按 Esc，尝试射击并观察敌人，按 Enter 恢复 | 场内有效射击消耗弹药，空枪不加分，打空约 0.6 秒后恢复 8 发，R 也能补满。暂停时敌人和战斗计数停住，恢复后继续原局 |
| 巷口水洼 | 第六波后观察小群。先点尾巴，再点墨蝌蚪头部或头部的朱印。观察点灯前后目标形态 | 尾巴判空枪，头部可命中。能在多只同屏时迅速分辨头、尾和朱印 |
| 糖葫芦摊、录像厅 | 观察点灯、墨身和掩体反馈。换到下一站时记下灯芯、光弹、获救数和分数 | 能分辨哪里可射、哪里挡弹。过站后当局资源没有意外重置 |
| 天桥 | 等一轮车铃，观察桥上居民和桥下墨车夫。各点一次居民、自行车和墨车夫可射部位 | 居民与自行车判空枪，桥栏挡弹，墨车夫可命中。车铃和居民受惊动作能对上，能看懂攻击预警 |
| 广场 | 按提示由尾到头净化八节。龙嘴开放后，分别射露出的朱砂核和龙颚 | 每次能看出当前开放的龙节。八节完成才开放龙嘴，龙颚挡弹，射中朱砂核后进入旧影院 |

## 第二轮 · 旧影院、火车站与三个重点场景

可以沿同一局继续。先用鼠标排查命中与可读性，再按需要重开。独立站台包和第三关 Boss 包可快速复现各自场景，跨章节和长片尾结果以三关候选为准。

| 到哪里 | 具体操作 | 通过标准 |
| --- | --- | --- |
| 旧影院前四站 | 依次过售票处、海报长廊、观众席、放映室。对出现硬化眼的目标试射一次，点灯或等它软化后再射可射区。观察墨伞开合 | 硬化时的无效反馈与软化后的命中反馈能区分。撑伞时射击无效，收伞过程中伞面挡弹，墨身露出后容易辨认 |
| 银幕前 | 先点一次放映机机身，再射左、中、右三盘的墨渍，最后射影核 | 机身无效。每净化一盘只切换对应的暖光，三盘完成后影核出现。净化影核后进入火车站，过场期间开枪不改变战斗计数 |
| 候车室、站台、车厢、灯座 | 每站观察一次关灯和点灯后的墨身，记下最难看到的敌人或预警。用同一目标试射硬化态和软化态 | 普通墨身、硬化眼、预警各有清楚区别，能判断该打灯、打怪还是等待。遇到预警看不清或反应时间太短，记录具体站点和目标 |
| 站台路人 A | 在受困时先点远离胸口的纸身，再打胸口墨团。获救后再点一次纸身 | 第一枪扣 50 分。胸口命中救出 1 人。获救后纸身判空枪，获救计数和分数没有重复变化。挣扎、脱困、致谢容易读懂 |
| 工作台「忘」字 | 观察从灯座拉到工作台的镜头。等上浮完成，从第 1 笔按当前光点打到第 7 笔。第 2 笔开放时，先试射图板里的第 2、3 笔交叉点，再射第 2 笔自己的光点 | 上浮阶段锁定射击。暗相也找得到光点。交叉点只擦伤上层第 3 笔，第 2 笔仍能单独净化。每笔的反馈与残迹可辨，第 7 笔后进入点灯片尾 |

在仓库根目录用下列命令快速复现，分别启动，测完先退出当前播放器。

```powershell
powershell -ExecutionPolicy Bypass -File .\gunforge\start_level_player.ps1 -Package paper.platform_passerby -Candidate
powershell -ExecutionPolicy Bypass -File .\gunforge\start_level_player.ps1 -Package paper.train_station_boss -Candidate
```

## 第三轮 · 片尾、重试与 PC 显示

1. **自然播放。** 第七笔后放下鼠标，听完约 58 秒。依次看工作台点灯、夜市近景、城市全景、回工作台。听两句旁白是否清楚，字幕是否跟得上，配乐是否盖住人声。片尾前后的灯芯、光弹、救援和分数应一致，具体数值以自己的这局为准。
2. **跳过片尾。** 另一次打完 Boss 后，在全景段按 Enter 或 Esc。应进入同一局结算，片尾音轨停止。片尾进行时左键和 R 不应改变战斗计数。
3. **失败重试。** 另开一轮，在工作台或更早站点让灯芯耗尽，用鼠标点击重试。三关候选应回巷口，分数和救援清零，灯芯和弹药恢复新局值。确认能再次开枪。
4. **窗口与全屏。** 在战斗中按 F11 切换两次，分别用鼠标打内容区中心和靠边的可辨目标。确认画面完整，指向和命中一致。按 H 确认纸环准星可切换。窗口缩放后检查 HUD 是否裁掉文字、挡住目标或让数字难读。
5. **片尾选版。** 打开摊位近景和七组同帧对照，比较灯光、纸纹和近景到全景的色温衔接。反馈「保留原版」「采用暖杏调色」或「再调」，附上具体部位。独立对照构建可按报告直接跳到叠化前观看。
