# 出图路径调整

日期：2026-11-03。依据审核人要求：“修改一下方案，直接用 gpt 出图”。

当前默认使用内置 GPT 图像生成与编辑工具，不需要出图 API 密钥。旧版要求提供火山方舟、百炼或 OpenAI API 密钥的前置已撤销。正式模型/底层版本若工具没有暴露，记录空值，不自行猜测型号。

已更新四份现行文档：美术方案 v0.3、美术任务 v0.2、GunForge 总方案 v0.6、首作设定中的美术生产说明。历史评审和修改记录保留。

主要变化：

- T01 改为最多三次 GPT 能力小样：透明输出、编辑保真和参考图关联。
- 场景改为按白模逐层生成/提取透明素材；包围盒、层级与关节数据由本地处理和核对产生，不要求结构化拆层返回。
- 色板通过提示词、锚点与 C04 检查控制；源尺寸按真实输出归一化，不假设工具具有其他供应商参数。
- 工具未披露费用时记 null/not_reported；任务改用调用次数上限，失败与重试计入。每批最多十次，0A 最多一百二十次。原现金预算仅供以后单独启用的外部服务使用。
- 特殊镜头默认采用 GPT 场景层和关键帧交引擎演出；外部视频生成单独启用。
- 审核点与真实 0B 批量门槛保留，离线预审不代替正式验收。

配置、首次初始化脚本、工具说明、执行状态和旧 T00 报告的当前路径说明已同步。已有检查证据未被改写为通过。图像生产下一步按新 T01 能力小样执行；本次修改本身没有调用生成工具。
