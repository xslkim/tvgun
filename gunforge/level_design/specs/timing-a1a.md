# Timing and replay contract — A1a implementation

- The simulation clock is 60 Hz, with up to 120 catch-up steps per render frame. Excess debt is retained, not truncated. Scene painting never advances game time.
- Live mouse/network events enter one FIFO, bounded to 512 entries. SHOT binds the most recently submitted geometry; no submitted frame is a rejection without ammo loss. Queue age is local time since enqueue (250 ms default), independent of phone prediction; stale shots are rejected. Rejection diagnostics are bounded too.
- HTTP gameplay responses are deferred until consumption and preserve ok/hit/score. GET state is immediate. Pending requests are not parsed twice.
- Frozen debug `input` retains its legacy synchronous state result. It executes a zero-time input boundary through the queue and logs a virtual submission. `step` advances fixed ticks. This explicit compatibility choice differs from a future queued-only debugging API; do not mix the two silently.
- CPU pose composition is in g01/alley_pose.gd; it has no scene-tree, drawing, material or GPU readback dependency. g01 owns the frozen nearest-mask exposure formula. Paint consumes that pose. The actual submitted list, not the newest unpainted list, is bound to input. Pending events retain serialized source geometry and the hit result; current target permissions are rechecked at consumption.
- Native replay snapshots preserve rules, timers, pending inputs, clock debt, protocol sequencing, geometry references, display calibration and presentation phase. Assets must remain the same frozen build. HTTP completions must drain first. Restore rebases local queue age and protocol timestamps; it does not deserialize arbitrary objects.
- Legacy public-state comparisons normalize through the original Godot JSON numeric encoding; this removes parsed-number representation differences without altering model arithmetic. All discrete outcomes and the alpha-sampling results compare exactly. Native model restore is additionally tested bit-for-bit. Future data-runtime quantization must be declared before its comparison, never used to hide changed decisions.
- Baseline headless audio is disabled in model/snapshot tests. Cue/voice listening, real phone behavior and end-to-end display latency are not inferred from these tests.
